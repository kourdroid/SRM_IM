## 2025-02-12 - Inline functions in FlatList renderItem
**Learning:** React Native's `FlatList` component is sensitive to its `renderItem` prop receiving a new function reference on every render. If `renderItem` is defined as a non-memoized inline function within the component's render body, it causes unnecessary re-renders of all list items whenever the parent component re-renders (e.g. state changes like `isModalVisible`).
**Action:** Always wrap `renderItem` functions in `useCallback`. Ensure any functions it depends on (like `openIncidentDetails`) are also wrapped in `useCallback` to satisfy dependency rules and maintain stable references.
## 2025-02-28 - Stale closures in memoized list render items
**Learning:** When memoizing `renderItem` using `useCallback` for `FlatList` or `FlashList` in React Native, the dependency array must strictly include all state variables and helper functions referenced within the callback. Failing to do so causes a stale closure bug where the list item always renders with the initial state values, even after asynchronous updates to state variables.
**Action:** When adding `useCallback` to a render function, thoroughly inspect the entire function body to identify all external dependencies (state variables, props, or other functions that use them) and explicitly include them in the dependency array to ensure the callback has access to the most recent data.
## 2025-02-28 - Optimizing React Native FlashList item renders with inline functions
**Learning:** Using `React.memo` on a list item component (e.g. `IncidentCard`) is insufficient to prevent re-renders in `FlashList` if the `renderItem` prop passes an inline anonymous function to the item (e.g., `onPress={() => setSelectedIncident(item)}`). Even if `renderItem` itself is wrapped in `useCallback`, the child component receives a newly created `onPress` reference every time the `FlashList` invokes the render function for that item, defeating `React.memo`.
**Action:** To achieve true 100% memoization efficiency on the item level, refactor the list item component to accept the entire item data and a stable handler function (e.g., `handlePress`). Define the `handlePress` callback at the parent level using `useCallback`, and have the child component invoke it internally. This ensures props remain referentially identical between unchanged renders.
